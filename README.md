# Yasar Portfolio — Updated

Modernized React portfolio with:
- Framer Motion reveal, hover, tilt and scroll-progress animations
- Responsive mobile navigation
- Interactive project cards
- Premium dark visual system with gradients, grid, glow and glass effects
- Accessibility-friendly reduced-motion handling

## Run locally

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Before deploying
Update the placeholder email/LinkedIn values in:
`src/components/Contact.jsx`

Project/GitHub links can also be adjusted in:
`src/components/Projects.jsx`
